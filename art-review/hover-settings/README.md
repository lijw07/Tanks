# Hover and settings verification

Pointer hover highlights the relevant menu button in yellow. Focus follows the pointer and clears on exit, while keyboard navigation remains available.

Settings has only Volume and Key bindings. Players can change all eight actions and reset them; duplicate bindings are rejected and Escape cancels capture. Changes persist. Touch controls are enabled automatically on touch devices.

Native captures cover hover on Play, Settings, and Quit; settings at desktop, portrait phone, small phone, and short landscape sizes. Tests also exercise a remapped mine key, remapped camera and pause keys, persistence, and resetting the default camera key. The prior user settings are restored after testing.
